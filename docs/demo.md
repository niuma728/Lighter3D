# 现场演示步骤

运行便携目录中的 `Lighter3D.exe`，保持 `assets/` 和 `shaders/` 与程序在一起。底部面板显示状态与快捷键。

1. 闭合时按 F，展示“先打开上盖”的非法操作提示。
2. 左键拖动环绕，滚轮缩放，说明机身与上盖的金属材质；按 R 恢复默认视角。
3. 按 O 开盖，展示 115° 铰链旋转及机身、上盖、活动铰链的层次关系。开盖途中按 C，再按 O，可展示连续反向。
4. 从侧前方和上方观察内胆、防风罩真实通孔、带齿打火轮、支架和灯芯。
5. 按 F 点火。打火轮先旋转，约 0.08 秒出现火花，约 0.15 秒开始长出火焰，约 0.4 秒进入持续燃烧。
6. 燃烧时继续环绕，说明内外层网格、颜色变化、顶部摇曳以及附近金属的暖光。
7. 按 E，火焰约 0.3 秒内缩小消失，出现短暂烟雾，上盖保持打开。
8. 再按 F 点火，然后按 C，展示自动先灭火再关盖。点火刚开始就按 C，也不会在闭盖后重新冒火。
9. 按 Space 自动演示：闭合展示 1 秒 → 开盖 → 内部展示 1 秒 → 点火 → 燃烧 3 秒 → 主动灭火 → 再点火 → 燃烧 2 秒 → 自动灭火和关盖。
10. 演示中拖动和缩放仍有效。按 O、C、F、E 转为手动控制；再次按 Space 停止后续步骤。
11. 任意时刻按 R，立即复位模型、轮子、火焰、粒子、演示和摄像机。Esc 退出。

程序中显示的 FPS 由当前真实帧时间计算，通常受垂直同步与显示器刷新率限制。性能测试的命令及测量条件见 README。
